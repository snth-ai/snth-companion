## 2. Свёрнутый остров: текст справа

- Короткий текст **справа** на свёрнутом острове (на маке справа от notch, в правом «ухе»; на Windows справа внутри плашки/слота, во всех позициях `pos=<v>-<h>`; в боковых позициях (left/right middle) там, где «справа» уместно, решить и показать скринами).
- Формат по умолчанию (как написал Саша): `h:34% 2h`, `w:61% 3d`. Буква окна: five_hour = `h`, seven_day = `w`, третье окно (неделя модели) = `w` + первая буква модели как пришло в label (например `wO`), неизвестное = первые 2 символа id. Буквы и единицы одинаковые на обоих языках (это технические токены, как в CodexBar), подписи в настройках и tooltip по локали.
- Отсчёт до сброса: `< 1 ч` = `45m`; `< 24 ч` = часы, округление вверх (`2h`); `>= 24 ч` = дни, округление вверх (`3d`). Нет `resets_at` = без отсчёта. Окно сброшено (`resets_at` прошло) = `h:0%` без отсчёта.
- Цвет текста: обычный (как остальной текст острова, приглушённый) < 80, жёлтый 80-95, красный >= 95 или blocked. Когда показывается текст, отдельная точка лимитов не нужна (текст и есть индикатор). Когда текст выключен, работает старая точка (если она включена в настройках).
- Не ломать: wakeDot (уши), glyph состояния, анимации состояний (listening/thinking/speaking), notch-геометрию на маке. Во время активного состояния (запись, ответ, approval) текст можно прятать, если места нет; решение показать скринами. Ширину окна/слотов пересчитать.
- Tooltip / aria на тексте: полная строка `limitsSummary` (план, все окна, сброс).

## 3. Развёрнутый остров (наведение): компактнее

Саша: «такой большой штуки не нужно». Новый вид по умолчанию «компактный»:
- Одна строка на окно, мелкий шрифт, без заголовка-плана отдельной строкой (план можно мелко в конце/в tooltip): например `5ч ▪▪▪▫▫ 34% · 2ч` и `неделя ▪▪▪▪▫ 61% · 3д` (здесь подписи по локали, отсчёт в стиле настройки «время сброса»). Тонкая полоса или без полосы (настройка). Высота блока минимум в 2 раза меньше нынешней.
- Старый большой блок остаётся как вариант «подробно».
- Высоту окна острова (`360`) пересчитать: если компакт меньше, вернуть меньшую высоту, где можно.

## 4. Настройки (как в CodexBar), экран «Остров» (`app/src/screens/Island.tsx`)

Новая секция «Лимиты подписки» (показывать всегда, с подписью, что лимиты есть только у синтов на Claude/ChatGPT подписке). Поля:

1. **Свёрнутый вид**: `текст` (по умолчанию) / `только точка при 80%+` (как в 0.1.33) / `ничего`.
2. **Какое окно в свёрнутом**: `самое загруженное` (по умолчанию: максимальный used_pct, при равенстве 5ч) / `5 часов` / `неделя` / `оба` (`h:34% 2h  w:61% 3d`).
3. **Процент**: `использовано` (по умолчанию) / `осталось` (100 - used; цвета по-прежнему по used).
4. **Время сброса в свёрнутом**: `через сколько` (по умолчанию, `2h`/`3d`) / `не показывать`.
5. **Развёрнутый вид**: `компактно` (по умолчанию) / `подробно` (блок 0.1.33) / `не показывать`.
6. **Время сброса в развёрнутом**: `через сколько` (по умолчанию, `через 2ч`/`in 2h`) / `по часам` (`18:20`, `пн 03:00`, как сейчас).

Живое превью свёрнутого текста рядом с выбором (на мок-данных или на реальном снимке, если есть). Изменения применяются сразу, без перезапуска.

Хранение: в `IslandSettings` (`crates/connect-core/src/island.rs`) новое поле `limits: LimitsDisplay` с `#[serde(default)]` и `skip_serializing_if` на дефолт (старый файл настроек читается, дефолт ничего не пишет), enum-ы с serde rename_all lowercase. Установка: расширить `island_set` (опциональные параметры) или отдельная команда; если новая Tauri-команда, то main.rs + build.rs + capability, `src/acl_check.rs` это проверяет. Настройки должны доезжать до окна острова (как сейчас `position`/`voice_reply` в `IslandView`/`IslandDto`).
